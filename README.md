# Canon Multi-Monitor Pro (Android)

تطبيق احترافي بنظام أندرويد يحول الهاتف إلى شاشة مراقبة إخراجية (Multi-Camera Director's Monitor) تتيح عرض البث المباشر لما يصل إلى 5 كاميرات كانون (Canon EOS / R-Series) في نفس الوقت عبر شبكة الواي فاي بدون تأخير (Ultra-Low Latency).

## المميزات:
1. يدعم بروتوكول Canon CCAPI الرسمي عبر تدفقات MJPEG فائقة السرعة.
2. شبكة عرض مقسمة (Grid View) وشاشة كاملة لكل كاميرا بلمسة واحدة.
3. عداد إطارات حقيقي (FPS) ومؤشرات حالة الاتصال لكل كاميرا.
4. إمكانية تعديل عنوان IP لكل كاميرا مباشرة من شاشة التطبيق.
5. زر تحكم بالتقاط الصور أو بدء التسجيل لجميع الكاميرات معاً أو لكاميرا منفردة.
6. مهيأ بالكامل للبناء السحابي التلقائي عبر GitHub Actions لإنتاج ملف APK بضغطة زر.

## طريقة الحصول على ملف APK عبر GitHub في 3 دقائق:
1. قم بإنشاء مستودع جديد (New Repository) في حسابك على موقع GitHub.
2. قم برفع محتويات هذا المجلد بالكامل إلى المستودع.
3. توجه إلى تبويب **Actions** في أعلى المستودع، وستجد أن GitHub بدأ تلقائياً في بناء التطبيق (`Build Canon Monitor APK`).
4. بعد دقيقة أو دقيقتين ستكتمل العملية، انقر على البناء وستجد ملف **`CanonMultiMonitor-Debug-APK`** جاهزاً للتحميل مباشرة بصيغة `.apk`.
